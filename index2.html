System analysis & database design

LXT Primary School - Inventory System

Professional system design · Integrated Situation · 20 December 2024 · Database: Saint_Anne

a. Data Flow Diagrams (DFD)

The context diagram shows the system boundary; the Level 1 diagram decomposes the system into its main processes and persistent data stores.

DFD Level 0 — Context Diagram

One external entity exchanges data with the complete Saint Anne stock management system. Internal data stores are omitted at this level.

External entity System process Arrow direction indicates data-flow direction

DFD Level 1 — Process Decomposition

Process 0 is decomposed into authentication, product maintenance, stock movement recording, and period-report generation.

External entity Process Data store Labeled arrows show named data flows
Data stores: D1 Users, D2 Products, D3 Stock_In, and D4 Stock_Out. Report generation reads the product catalog and stock movement records. Total purchase cost is quantity × unit price; stock balance is total stock-in quantity − total stock-out quantity.

b. Entity Relationship Diagram (ERD)

Relational design for the Saint_Anne database. Each stock transaction references one product; each product may have multiple stock-in and stock-out transactions.

PK Primary key FK Foreign key UQ Unique value 1 → 0..* One product can have zero or many movement records
Design notes: StockIn_Id and StockOut_Id are added as transaction primary keys so each movement has a unique identifier. Product_Id in both transaction tables is a foreign key to Products.Product_Id. Total_Price = Quantity × Unit_Price. Password_Hash represents a securely hashed password, not a plain-text password. User is kept separate because the given requirements do not specify which staff member records each transaction.
